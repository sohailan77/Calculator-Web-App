# 🔢 Calculator Web App
  
A modern and responsive calculator built using **HTML, CSS, and JavaScript**, featuring two different themes and interactive calculation functionality.

## 📌 About the Project

This project was developed primarily to revise and practice important JavaScript concepts through hands-on implementation. It provides a simple interface for performing basic mathematical calculations.

## ✨ Features

- Basic mathematical calculations.
- Two different themes (Light & Dark).
- Responsive design for different screen sizes.
- Interactive and user-friendly interface.
- Clean and minimal design.

## 🛠️ Technologies Used

- **HTML5** – Structure of the calculator.
- **CSS3** – Styling, layout, and responsive design.
- **JavaScript (ES6+)** – Calculator functionality and interactivity.

## 🧠 JavaScript Concepts Practiced

- DOM Manipulation
- Event Handling
- Functions
- Conditional Statements
- Variables and Data Types
- Operators
- Logic Building
